采用标准 uni-app(H5) 工程结构：`src/main.js` 通过 `createSSRApp` 挂载根组件 `App.vue`，页面路由由 `src/pages.json` 声明（仅 `pages/index/index` 单页）。业务逻辑集中在 `src/pages/index/index.vue`，以 `<script setup>` 组合式 API 组织状态（`result`/`partial`/`state`）与事件回调（`@result`/`@partial`/`@error`/`@state`），并通过 `getSign` 注入 ASR 签名接口地址。组件使用两种引入方式并存：模板中直接写标签名走 easycom 自动注册，同时显式 `import UniWebVoiceInput from '@/uni_modules/...` 作为稳定导入；SDK 能力探测则通过相对路径 `@/uni_modules/uni-web-voice-input/js_sdk/uni-web-voice/index.js` 直接引入。构建层由 `vite.config.ts` 接入 `@dcloudio/vite-plugin-uni`，依赖版本统一锁定在 `3.0.0-4070620250821001` 的 DCloud 预发布通道。
