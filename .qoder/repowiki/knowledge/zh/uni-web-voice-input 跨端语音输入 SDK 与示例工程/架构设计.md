根目录作为 npm 包入口（`package.json` 的 `main` / `module` / `exports` 指向 `uni_modules/uni-web-voice-input/js_sdk/...`），将同一份源码同时打包为 DCloud 插件市场可消费的 uni_modules 与 npm 包；`demo_app` 子模块通过 uni-app + Vite 构建，引用该 SDK 组件与 JS SDK 以验证多端行为。SDK 侧通过 `getSign` / `signUrl` / `fetchSign` 注入 ASR 签名实现后端解耦，平台能力探测集中在 SDK 内部（如 `isHarmonyWebview`），对 demo_app 透明暴露统一的 Vue3 组件 API。
